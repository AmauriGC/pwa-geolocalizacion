¿Por qué pedimos tu ubicación?

Adjuntamos tus coordenadas al reporte para que el equipo técnico sepa exactamente dónde está el problema.

  • Se lee una sola vez, solo cuando pulses el botón. No hay rastreo continuo.
  • No se comparte con terceros ni se usa para publicidad.
  • Si prefieres no compartirla, puedes elegir tu zona a mano.

Después de pulsar «Permitir», tu navegador mostrará su propio aviso: elige Permitir.

Elige tu zona manualmente

Para reactivar el permiso:

  • Chrome (Android / escritorio): toca el candado junto a la dirección → Permisos → Ubicación → Permitir.
  • iPhone (Safari): Ajustes → Safari → Ubicación → Preguntar o Permitir.
  • iPhone (app instalada): tiene su propio permiso, separado de Safari. Revísalo en Ajustes → Privacidad → Localización.
